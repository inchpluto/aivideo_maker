# 0.2.1 前端可靠性回归记录

日期：2026-10-16。工作分支：`arena/2f2d2e75-aivideo-maker`。范围：智能补全工作台、模型选择器、语音库生命周期；不改项目 schema，不进行整仓重构。

## 本轮实际问题与修复

### 1. 智能补全结果跨项目写入

原组件在异步生成／上传完成后直接调用 `updateProject(previous => ...)`，只判断 previous 是否存在，没有校验项目身份。切换 A → B 时，A 的结果可能写入 B；A → B → A 也无法仅靠字符串 ID 判断请求是否还有效。

本轮新增 `useProjectOperations`，把操作绑定到本次已提交的项目生命周期。切换／卸载会 abort，迟到的成功／失败均被忽略；React updater 执行时再次校验生命周期和项目 ID。相同操作类型用 ref 中的占用记录同步去重，防止两次点击发生在 state 更新之前重复提交。

图片上传增加 AbortSignal：FileReader 阶段可直接终止，不再继续发送 HTTP；媒体上传沿用既有取消路径。已接收的服务器／供应商任务不一定因客户端断开而停止，本轮不保证供应商计费取消，也不自动重试。

### 2. 提示词与剪贴板

旧提示词按 task ID 缓存，任务 ID 在多个项目间复用，同项目资料变更也不失效。本轮只对展开卡片按当前 project／task 重新推导提示词，避免复制旧资料。剪贴板成功通知等待真实写入完成，权限拒绝或接口缺失时显示失败。

### 3. 本地 TTS 与语音库

- 打开语音库／切换引擎只 GET 状态，不再隐式 POST 启动 GPU 服务；“启动服务”是明确用户操作。服务端显式设置 `LOCAL_TTS_AUTOSTART=true` 的行为保留。
- 每次读取结束后才安排下一次轮询；慢请求不会叠加；重复启动点击复用在途操作。
- 切换引擎／关闭组件时中止请求、清理轮询和请求超时计时器；即使旧 fetch 忽略 abort 并迟到返回，也不能覆盖新状态。
- `failed` 优先于 `managed`，终态失败停止轮询并显示原因；超时／网络错误可见，不吞异常。
- 语音包、模型选择和服务探测使用一致的引擎；切换包停止旧样音、关闭旧编辑器。语音包尚未载入时禁用添加／启动入口。

### 4. 模型选择与存储受限

Hook 的 task 改变后立即选取对应路由；同页其他选择器通过事件即时同步；浏览器 storage 事件触发刷新。按 task 串行发送配置 PUT，避免当前标签页快速切换造成旧请求晚写覆盖新选择。localStorage 写入失败时保留当前页面内存副本，服务端 PUT 仍会执行。

该队列不是跨标签页或跨设备锁；网络失败时本地选择保留，可在 API 中心重试，不声称服务端已保存成功。

## 新增行为测试

`pnpm test:frontend` 使用 React 18.3.1 test renderer 挂载真实 Hook 和真实 JSX 组件；esbuild 只负责测试转译。两项工具均为精确锁定的开发依赖。

共 **31 组行为回归**，覆盖：

- A → B → A、卸载、同一时刻重复点击、延迟 React updater 的项目身份校验。
- 生成结果迟到、图片上传中止／迟到、正常同项目回填。
- 同项目修改后提示词刷新、剪贴板拒绝。
- 打开／切换语音库不启动 TTS；明确启动去重；慢轮询不重叠；引擎切换后旧结果被忽略。
- managed + failed 的优先级、超时、组件关闭后的请求与计时器清理。
- 模型 task 切换、同页多选择器同步、storage 事件、quota 错误、连续 PUT 次序与失败后的队列恢复。
- 语音包与模型一致、切换包停止播放并关闭旧编辑器。

这些是受控组件行为测试，**不是完整真实浏览器／GPU／云供应商验收**。
