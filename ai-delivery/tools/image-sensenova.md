# Image · 商汤 SenseNova（日日新）生图备用提示词卡 —《雾港来信》

> 用途：**备用文生图工具**。当主工具（ChatGPT）不可用时，可在商汤 SenseNova 生图（或兼容的文生图接口）中生成角色、场景与首帧底图。
> 工具目录：`ai-delivery/tools/image-sensenova.md`
> 对应输入来源：`text/_text-bible.md`

## 使用方法

1. **按顺序**逐张生成：**角色图（2 张）→ 场景图（3 张）→ 首帧图（6 张）**，先锚定角色，再搭场景，后叠加镜头。
2. 将**每条提示词**完整复制到 SenseNova 生图输入框，发送生成。
3. 生成后**按产出文件名下载 / 重命名保存**到 `out/image/`。
4. 全局硬规格：**16:9 横构图 1280x720、PNG、无文字无水印**。角色锚点跨图一致：**沈知遥 = 芥末黄雨衣 + 旧银色钥匙 + 黑色齐肩短发 + 琥珀眼**；**顾川 = 深绿旧航海夹克 + 银色口哨 + 深色短发**。
