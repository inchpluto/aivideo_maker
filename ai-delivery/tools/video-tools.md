# Video · 图生视频提示卡（MiniMax H3 / 豆包对话 / 可灵 AI 等）—《雾港来信》

> 用途：用视频生成工具（MiniMax H3 / 豆包对话 / 可灵 AI 等）把 6 个镜头的首帧动起来。
> 工具目录：`ai-delivery/tools/video-tools.md`
> 对应输入来源：`text/_text-bible.md`（镜头大纲）

## 使用方法

1. **图生视频优先**：用 `out/image/shot-XX.png` 作为**输入第一帧**，再粘贴下面该镜头的**运动描述**。
   - 若工具**不支持图生视频**，则改用文生视频，并把该镜头卡中的主体 / 环境 / 首尾帧用提示词文本完整描述一遍。
2. 每个镜头独立生成。产出保存为 `out/video/video-01.mp4` … `video-06.mp4`。
3. **时长严格等于下表**（±0.5s）：
   | 输出 | 首帧 | 时长 |
   |---|---|---|
   | video-01 | shot-01.png | 4s |
   | video-02 | shot-02.png | 5s |
   | video-03 | shot-03.png | 3s |
   | video-04 | shot-04.png | 4s |
   | video-05 | shot-05.png | 4s |
   | video-06 | shot-06.png | 5s |
4. **全局硬规格**：输出 **MP4、H.264、1280x720、25fps、无声轨**。所有镜头保持连续性锚点：雨夜冷蓝色板 / 芥末黄雨衣与旧银色钥匙 / 沈知遥与顾川外观一致。

## 卡片 1 · 镜头 01「雨夜入口」
- **产出文件名**：`video-01.mp4` · 时长 **4s**
- **输入首帧**：`out/image/shot-01.png`
- **运动 / 摄影提示词（自包含）**：
  > 输入首帧是一位穿芥末黄雨衣、胸前挂旧银色钥匙吊坠的黑色齐肩短发女性，在雨夜空旷的废弃雾港码头（木栈道、湿润反光、雾气沿地面流动、远处孤立信号灯）。主体动作：她缓慢走入雨幕，从远处向镜头方向移动，最终停在画面中；她停下，微微低头看向地面方向（停在一只异常信件前）。环境动作：细密的雨不停落下，地面水洼持续反光，雾气流动，远处的琥珀信号灯忽明忽暗。摄影机运镜：平视机位，缓慢推进（纵向推近），纵深构图。光线：冷蓝主光 + 远处一点琥珀信号灯，潮湿高对比。首帧为"空旷码头 + 孤立人物"，尾帧为"人物停在异常信件前"。负面提示：无文字、无水印、无字幕、无多余路人、画面不要闪烁抖动、人物外观不要变。
- **备注**：镜头大纲第 01 镜 / 场景 1 / 远景平视推进。总 25 秒的一部分。
