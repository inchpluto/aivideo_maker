# Voice · VoxCPM-2 开源 TTS 对白提示卡 —《雾港来信》

> 用途：使用开源 TTS **VoxCPM-2**（或基于参考音色的开源 TTS）合成 3 句角色对白。
> 工具目录：`ai-delivery/tools/voice-voxcpm2.md`
> 对应输入来源：`text/_text-bible.md`

## 使用方法

1. 这类开源 TTS 需要「**参考音色 + 文本**」。参考音色已在角色声线描述中给出，请选用或录制最接近的参考人声。
2. 将每张卡片的**逐字文本**原样复制为合成文本（**逐字不能改一个字**），再按卡片中的音色 / 情绪 / 语速 / 停顿 / 重音要求设置参数。
3. 合成后校对：把对白文字投屏逐句比对，**文字内容不得有任何增删改**。
4. 保存产物到 `out/audio/`，全局硬规格：**WAV、44100Hz、单声道、16bit**：
   - `voice-ep1d1.wav`
   - `voice-ep1d2.wav`
   - `voice-ep1d3.wav`

## 卡片 1 · 对白 D1
- **产出文件名**：`voice-ep1d1.wav`
- **说话人**：沈知遥（主角，女 / 24 岁）
- **逐字文本（不得改动）**：
  > 这封信……是他的字
- **声线描述**：青年女声，清澈偏低，近讲带轻微气声，普通话。
- **情绪**：迟疑（认出父亲笔迹后的震惊与犹豫）
- **情绪强度**：中
- **语速**：偏慢（发现线索前平时偏慢；此句属"认出笔迹"的迟疑时刻，保持慢速）
- **停顿 / 重音要求**：在省略号「……」（第一句末"信"字后）作一次明显停顿；重音落在「他」「字」二字；句尾略拖、收轻。
- **一句话表演指令**：像是看到了不该出现的东西，声音很低，迟疑地把话挤出来，关键词带颤。

## 卡片 2 · 对白 D2
- **产出文件名**：`voice-ep1d2.wav`
- **说话人**：顾川（配角，男 / 约 30 岁）
- **逐字文本（不得改动）**：
  > 灯塔熄了十年，你不该去
- **声线描述**：低沉干净，辅音收紧，句间停顿长，普通话。
- **情绪**：克制（警告，试图阻止）
- **情绪强度**：中低（克制但坚定）
- **语速**：慢（警告时语速反而变慢）
- **停顿 / 重音要求**：在逗号「，」处停一拍；重音落在「你」「不该」「去」；"灯塔熄了十年"说硬而有份量。
- **一句话表演指令**：压低声音、咬着字说，像在下最后通牒，冷静但带着阻拦的力度。

## 卡片 3 · 对白 D3
- **产出文件名**：`voice-ep1d3.wav`
- **说话人**：沈知遥（主角，女 / 24 岁）
- **逐字文本（不得改动）**：
  > 如果答案在上面，我就必须去
- **声线描述**：青年女声，清澈偏低，近讲带轻微气声，普通话。
- **情绪**：坚定（做出走向灯塔的决定）
- **情绪强度**：中高
- **语速**：中等（发现线索后略快，但此处为决心，字句清晰有力，不急促）
- **停顿 / 重音要求**：在逗号「，」处短停；重音落在「答案」「必须」「去」；"如果答案在上面"稍留悬念，"我就必须去"收紧咬字增强决心。
- **一句话表演指令**：眼神定住，声音由低转实，节奏稳，最后"必须去"落地有力，不带回头的余地。

## 音符与一致性

- 三条对白须与「角色声线」锚点一致：沈知遥=青年女声清澈偏低带气声；顾川=低沉干净辅音收紧句间停顿长。
- 情绪走向与剧情弧光一致：D1 迟疑 → D2 克制阻拦 → D3 坚定执行。
- 合成格式统一为 **WAV 44100Hz 单声道 16bit**，文件名见上。
