# Image · ChatGPT 生图提示词卡 —《雾港来信》

> 用途：在 **ChatGPT 生图**（也兼容 DALL·E / Midjourney / 即梦 等其他文生图工具）中生成角色、场景与首帧底图。
> 工具目录：`ai-delivery/tools/image-chatgpt.md`
> 对应输入来源：`text/_text-bible.md`

## 使用方法

1. **按顺序**逐张生成：**角色图（2 张）→ 场景图（3 张）→ 首帧图（6 张）**。
   先定好角色外观，再搭场景，最后让首帧同时代入"角色 + 场景 + 镜头"，这样角色识别锚点才能跨图一致。
2. 把下面的**每一条提示词**完整复制到 ChatGPT 生图对话框（提示词均已自包含，无需再查其它文件），发送生成。
3. 生成后，**按每张卡片标注的产出文件名下载 / 重命名保存**到 `out/image/`。
4. 全局硬规格（每条提示词均已内置、仍须在生成后核对）：
   - 尺寸：**16:9 横构图 1280x720**
   - 格式：**PNG**（无文字、无水印、无签名）
   - 角色一致锚点：**沈知遥 = 芥末黄雨衣 + 旧银色钥匙 + 黑色齐肩短发 + 琥珀眼**；**顾川 = 深绿旧航海夹克 + 银色口哨 + 深色短发**。所有带人物的图必须严格保持。

## 生成顺序与一致性提醒

- **顺序**：角色图（char-*）→ 场景图（env-*）→ 首帧图（shot-*）。先锚定角色，再定空间，后叠加镜头。
- **角色锚点必须跨图一致**：
  - 沈知遥 = 芥末黄雨衣 + 旧银色钥匙 + 黑色齐肩短发 + 琥珀眼；
  - 顾川 = 深绿旧航海夹克 + 银色口哨 + 深色短发。
- **全局硬规格**：所有图 16:9 横构图 1280x720、PNG、无任何文字/水印/签名。首帧图输出后即是 `video-XX` 的输入首帧。
